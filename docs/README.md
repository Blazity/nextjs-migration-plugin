# Documentation

This directory holds canonical product and architecture documentation for `nextjs-migration-plugin`.

## Layout

| Path | Purpose |
| --- | --- |
| [`specs/`](specs/) | Standalone product/design specs that define intended behavior. |
| [`adrs/`](adrs/) | Architecture decision records and long-lived rationale. |

Implementation plans live in [`.ai/plans/`](../.ai/plans/). Research artifacts live in [`.ai/research/`](../.ai/research/). Runtime plugin knowledge lives in [`knowledge/`](../knowledge/).
